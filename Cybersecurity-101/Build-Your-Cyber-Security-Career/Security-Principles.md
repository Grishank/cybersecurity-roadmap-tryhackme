# 🔐 Task 2 — CIA

The CIA Triad is one of the most important security models in cybersecurity.

## CIA Triad

| Principle | Description |
|---|---|
| Confidentiality | Prevent unauthorized access |
| Integrity | Ensure data accuracy and trustworthiness |
| Availability | Ensure systems and data remain accessible |

## Examples

### Confidentiality
- Encryption
- Access controls
- Multi-factor authentication

### Integrity
- Hashing
- Digital signatures
- File verification

### Availability
- Backups
- Redundancy
- DDoS protection

---

# ⚠️ Task 3 — DAD

The DAD Triad represents the opposite of CIA and explains the goals of attackers.

## DAD Triad

| Principle | Meaning |
|---|---|
| Disclosure | Unauthorized exposure of information |
| Alteration | Unauthorized modification of data |
| Destruction | Loss or disruption of systems/data |

DAD helps analysts understand:
- Attacker objectives
- Security failures
- Potential impacts of cyberattacks

# 🛡️ Task 5 — Defence-in-Depth

Defence-in-Depth uses multiple security layers to protect systems.

## Common Security Layers

| Layer | Example |
|---|---|
| Physical Security | Locks, cameras |
| Network Security | Firewalls, IDS |
| Endpoint Security | Antivirus, EDR |
| Application Security | Secure coding |
| Data Security | Encryption |
| User Security | MFA, awareness training |

If one layer fails, additional layers continue protecting the system.

# 🚫 Task 7 — Zero Trust versus Trust but Verify

## Trust but Verify

Traditional security assumed internal systems were trustworthy.

This approach:
- Trusted internal users
- Verified suspicious activity later

This model is now considered weaker against modern threats.

---

## Zero Trust

Zero Trust follows the principle:

> “Never Trust, Always Verify”

Zero Trust requires:
- Continuous authentication
- Strict access validation
- Identity verification
- Least privilege enforcement

Zero Trust helps reduce:
- Insider threats
- Lateral movement
- Unauthorized access

---

# ⚡ Task 8 — Threat versus Risk

Understanding the difference between threats and risks is critical in cybersecurity.

## Threat

A threat is:
- A potential danger
- Something capable of causing harm

Examples:
- Malware
- Hackers
- Phishing attacks
- Insider threats

---

## Risk

Risk is:
- The likelihood a threat will cause damage
- The impact of a successful attack

Risk depends on:
- Vulnerabilities
- Exposure
- Existing security controls
