# 🧠 Room Overview

The **CyberChef: The Basics** room introduces **CyberChef**, a powerful browser-based tool widely used by cybersecurity professionals for encoding, decoding, encryption, hashing, data transformation, and forensic analysis.

The room focuses on:
- CyberChef fundamentals
- Interface navigation
- Data transformation
- Encoding and decoding
- Hashing operations
- CyberChef recipes
- Practical analysis workflows

This room builds foundational knowledge required for:
- SOC investigations
- Malware analysis
- Threat intelligence
- Incident response
- Data decoding
- Security analysis workflows

# 🍳 Task 1 — Introduction

CyberChef is often called the:

> “Swiss Army Knife for Cybersecurity”

It allows analysts to quickly:
- Decode data
- Convert formats
- Analyze payloads
- Transform suspicious content
- Automate repetitive operations

CyberChef works entirely inside the browser and supports hundreds of operations.

---

# 🌐 Task 2 — Accessing the Tool

CyberChef is web-based and can be accessed directly through a browser.

## Common Uses

- Decode Base64
- Analyze suspicious strings
- Convert encodings
- Extract indicators
- Transform data formats

---

# 🧭 Task 3 — Navigating the Interface

The CyberChef interface consists of several main sections.

## Main Components

| Section | Purpose |
|---|---|
| Input Panel | Original data |
| Recipe Panel | Operations workflow |
| Output Panel | Transformed result |
| Operations Search | Find available tools |

# 🍽️ Task 6 — Your First Official Cook

CyberChef workflows are called **recipes**.

A recipe combines multiple operations into a reusable analysis chain.

## Example Recipe Workflow

```text
Base64 Decode → URL Decode → Extract Strings
```

# 🔐 Common CyberChef Operations

| Operation | Purpose |
|---|---|
| Base64 Decode | Decode Base64 data |
| URL Decode | Decode URL encoding |
| From Hex | Convert hexadecimal |
| To Hex | Encode as hexadecimal |
| MD5/SHA Hashing | Generate hashes |
| XOR | XOR transformations |
| Extract URLs | Identify URLs in data |
