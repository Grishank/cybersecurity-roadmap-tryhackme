# 🏢 Task 1 — Introduction to SOC

A **Security Operations Center (SOC)** is a centralized team responsible for:
- Monitoring systems
- Detecting threats
- Investigating incidents
- Responding to attacks
- Protecting organizational infrastructure

SOC teams work continuously to:
- Identify malicious activity
- Reduce attacker dwell time
- Improve detection capabilities
- Coordinate incident response

---

# 🧩 Task 2 — Purpose and Components

## Main Goals of a SOC

- Threat detection
- Incident response
- Log monitoring
- Threat hunting
- Security visibility
- Risk reduction

## Common SOC Components

| Component | Purpose |
|---|---|
| SIEM | Log collection and analysis |
| EDR | Endpoint detection |
| SOAR | Automation and response |
| Threat Intelligence | IOC and attacker tracking |
| IDS/IPS | Intrusion detection |

# 👥 Task 3 — People

A SOC contains multiple security roles.

## Common SOC Roles

| Role | Responsibility |
|---|---|
| Tier 1 Analyst | Alert triage |
| Tier 2 Analyst | Investigation |
| Tier 3 Analyst | Advanced response |
| Threat Hunter | Proactive hunting |
| Incident Responder | Containment and recovery |
| SOC Manager | Team coordination |

---

# 🔄 Task 4 — Process

SOC operations usually follow an incident response lifecycle.

## Typical SOC Workflow

1. Alert generated  
2. Alert triage  
3. Investigation  
4. Containment  
5. Eradication  
6. Recovery  
7. Lessons learned  

## Important Concepts

- False positives
- Indicators of Compromise (IOCs)
- Escalation procedures
- Documentation
- Playbooks
