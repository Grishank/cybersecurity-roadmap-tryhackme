# 🧠 Room Overview

The **Logs Fundamentals** room introduces the importance of logs in cybersecurity investigations and teaches how analysts use logs to detect, investigate, and respond to security incidents.

The room focuses on:
- Log fundamentals
- Types of logs
- Windows Event Logs
- Web server access logs
- Log analysis techniques
- Investigation concepts

This room builds essential SOC and blue-team skills required for:
- SOC Analysts
- Incident Responders
- Threat Hunters
- Security Investigators

# 📖 Task 1 — Introduction to Logs

Logs are records generated by:
- Operating systems
- Applications
- Security tools
- Servers
- Network devices

## Why Logs Matter

Logs help analysts:
- Detect attacks
- Investigate incidents
- Monitor systems
- Track user activity
- Identify suspicious behavior

---

# 🧩 Task 2 — Types of Logs

Different systems generate different log types.

## Common Log Types

| Log Type | Purpose |
|---|---|
| System Logs | OS activity |
| Application Logs | Program activity |
| Security Logs | Authentication and security events |
| Network Logs | Traffic monitoring |
| Web Logs | HTTP requests |
| Firewall Logs | Blocked/allowed traffic |

## Important Information Found in Logs

- Timestamps
- Usernames
- IP addresses
- Actions performed
- Error messages
- Authentication attempts

---

# 🪟 Task 3 — Windows Event Logs Analysis

Windows systems generate detailed event logs.

## Important Windows Event Categories

| Category | Purpose |
|---|---|
| Security | Login and authentication events |
| System | System-level activity |
| Application | Software-related events |

## Common Investigation Areas

- Failed login attempts
- Account lockouts
- Privilege escalation
- Service creation
- Process execution

## Important Concepts

- Event IDs
- Log filtering
- Timestamp analysis
- Correlation between events

---

# 🌐 Task 4 — Web Server Access Logs Analysis

Web server logs record HTTP activity.

## Common Web Log Information

- Client IP address
- Requested URL
- HTTP method
- Status code
- User-Agent
- Timestamp

## Common Attack Indicators

- SQL injection attempts
- Directory traversal
- Brute-force login attempts
- Suspicious User-Agents
- Excessive failed requests

# 🛡️ SOC / Blue Team Perspective

Logs are one of the most important data sources inside a SOC.

SOC analysts use logs to:
- Investigate alerts
- Detect malicious activity
- Track attacker behavior
- Identify compromised accounts
- Correlate security events

Important investigation sources include:
- Windows Event Logs
- Authentication logs
- Firewall logs
- Proxy logs
- Web server logs
