# 🔍 Task 1 — Introduction to Digital Forensics

Digital forensics involves:
- Collecting evidence
- Preserving evidence
- Analyzing systems
- Investigating incidents
- Recovering digital artifacts

## Main Goals

- Identify attacker activity
- Determine attack timeline
- Recover evidence
- Support incident response
- Maintain legal integrity

# 💾 Task 3 — Evidence Acquisition

Evidence acquisition focuses on safely collecting data from systems.

## Common Evidence Sources

| Evidence Type | Examples |
|---|---|
| Disk Data | Files, deleted files |
| Memory Data | Running processes |
| Logs | Event logs |
| Browser Data | History, cookies |
| Network Data | PCAP files |

## Important Principle

Evidence must remain:
- Unmodified
- Verifiable
- Properly documented

---

# 🪟 Task 4 — Windows Forensics

Windows systems contain many valuable forensic artifacts.

## Important Windows Artifacts

- Event Logs
- Registry
- Prefetch files
- Browser history
- User accounts
- Scheduled tasks

## Common Investigation Areas

| Area | Purpose |
|---|---|
| Event Viewer | System activity |
| Registry | System configuration |
| Temp Files | Malware traces |
| Startup Entries | Persistence detection |
